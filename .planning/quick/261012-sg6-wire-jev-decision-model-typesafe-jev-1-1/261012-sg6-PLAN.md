- POST https://openrouter.ai/api/alpha/decisions (NOT /api/v1). Headers: Authorization: Bearer KEY, Content-Type: application/json, optional X-Title: "Claude Code Jev skill".

- choice: criteria object {option: description|null}, max 255 options. score: criteria array of 2-10 level descriptions, lowest first. noul: criteria object with BOTH keys "true" and "false".
- Response: {id, model, provider, answers: {qid: {type, choice|score|noul, confidence?, probabilities?, legend?}}, usage: {input_tokens, output_tokens, cost?}}. noul has no confidence -> use abs(2p-1).
- Cost fallback: GET https://openrouter.ai/api/v1/generation?id=ID (Bearer) -> data.total_cost; best effort, 2 retries ~1 s apart, else null.
- Errors: {"error": {"code", "message", "metadata"}}. Retry only 429/502/503/524/529 with backoff 1 s, 2 s, 4 s (3 attempts). Other 4xx: print immediately.
