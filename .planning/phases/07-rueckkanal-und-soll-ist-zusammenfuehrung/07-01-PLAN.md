## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lokaler Prozess → Git-Remote `fork` (öffentlich) | einziger Schreibweg aus dem State-Ordner nach außen |
| Entwicklungs-Repo-Konfiguration → Remote-URL | URL wird aus `git remote get-url fork` gelesen |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | Push auf `origin` oder `paper-log` | mitigate | Remote/Branch als Konstanten, `validate_ref_name`, `fork`≠`origin`-Prüfung in `resolve_remote_url`, Test auf jede argv |
| T-07-02 | Tampering | Überschreiben fremder Commits auf `ibkr-log` | mitigate | Push ohne `--force`/`+`, Non-FF → `push-rejected`; Fremd-Autor wird gemeldet |
| T-07-03 | Information Disclosure | Firmen-E-Mail im öffentlichen Commit-Log | mitigate | feste Identität per `-c user.name/-c user.email`, `COMMIT_EMAIL` auf `.invalid` |
| T-07-04 | Information Disclosure | Konto-ID, Cash, Positionen öffentlich | accept | D-17: Paper-Konto, Operator hat Veröffentlichung ohne Maskierung entschieden |
| T-07-05 | Denial of Service | Credential-Dialog hängt den Lauf | mitigate | `GIT_TERMINAL_PROMPT=0`, `GCM_INTERACTIVE=never`, Timeout je Aufruf |
| T-07-06 | Tampering | CRLF-Umschreibung verfälscht den Ledger | mitigate | Bytes-Schreiben, `-c core.autocrlf=false`, `.gitattributes` `* -text`, Bytes-Test |
| T-07-07 | Tampering | fremde Dateien im Klon landen im Commit | mitigate | explizites `git add -- <namen>`, kein `-A` |
